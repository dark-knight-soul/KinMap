# Безопасность / Security

KinMap работает только в браузере и ничего не отправляет в интернет. Если вы нашли уязвимость (например, в шифровании файла с паролем или при открытии чужого файла), **не создавайте публичную задачу** — сообщите через [Security Advisories](../../security/advisories/new) этого репозитория.

KinMap runs entirely in the browser and sends nothing over the network. If you find a vulnerability (e.g. in password encryption or when opening an untrusted file), **do not open a public issue** — report it privately via this repository's [Security Advisories](../../security/advisories/new).
