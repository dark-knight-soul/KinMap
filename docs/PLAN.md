# План KinMap

**Цель:** семейное древо, которое работает из одного файла `KinMap.html` в браузере — без сервера, интернета и установки. Данные — только у пользователя, в файле древа `.kinmap`.

Распространение: файл `KinMap.html` в GitHub Releases + скрипты `build`/`start` для тех, кто собирает сам. GitHub Actions не обязательны (для публичных репозиториев они бесплатны, можно подключить позже).

## Технические решения этапа 2

- Файл `.kinmap` — zip (`mimetype`, `kinmap.json`, позже `photos/`), библиотека `fflate` (~8 КБ вместо JSZip ~100 КБ).
- Пароль — встроенная криптография браузера: PBKDF2-SHA256 600 000 повторов + AES-256-GCM; подсказка хранится открыто, но защищена от подмены.
- Хранилище браузера — своя маленькая обёртка над IndexedDB вместо Dexie. Копия в браузере — те же байты, что в файле (с паролем — зашифрована).
- Отмена — неизменяемые состояния древа, 200 шагов, быстрый ввод в одно поле склеивается в один шаг.

## Технические решения этапа 3

- Раскладка своя (`src/layout`): у каждого человека «полоса» шириной со всё его поддерево — просто, линейно по времени, без наложений. Минус: широкие ветки занимают больше места, чем в идеально плотной раскладке. Уплотнение — возможное улучшение позже.
- Вид «Семья» — «песочные часы» вокруг выбранного человека: предки сверху, потомки снизу, братья и сёстры рядом. «Всё древо рода» = «Потомки» от самого старшего предка.
- Перемещение и масштаб — свой код (~200 строк) вместо d3-zoom: меньше размер, полный контроль над жестами.
- Схема — чистый SVG с текстом (не HTML внутри SVG): пригодится для печати в PDF на этапе 7.

## Технические решения этапа 4

- Фото лежат в архиве `.kinmap` (`photos/<id>.webp`), в данных древа — только ссылки, подпись, дата и обрезка аватара. В сессии байты фото только добавляются, поэтому удаление фото отменяется через Ctrl+Z.
- Проверка данных (`src/model/checks.ts`): каждая неточная дата — диапазон дней; замечание только если ошибка есть при любом варианте («ок. 1960» не даёт ложных тревог). «Это не ошибка» сохраняется в файле.
- Проверки: смерть раньше рождения, больше 120 лет жизни, родитель младше 12 / мать старше 55 / отец старше 85, рождение после смерти матери (или >10 мес. после смерти отца), брак до рождения / младше 14 / после смерти, дети одной матери с разницей <8 мес., зацикленные связи, возможные дубликаты.

## Как проверим версию 1.0

- `KinMap.html` открывается двойным кликом без интернета.
- Древо из 50+ человек с повторными браками — без наложений; 5000 человек — без тормозов.
- Файл древа после перезапуска браузера открывается со всеми фото; с паролем — не открывается без пароля.
- GEDCOM из MyHeritage импортируется, экспорт открывается обратно, живые скрыты.
- Тесты «кем приходится» зелёные.
- Древо на 4 листах A4 склеивается — линии совпадают.
